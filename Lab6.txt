Migrating a Web Application to Docker Containers
To containerize a web application using Docker and execute it inside a container.
Step 1: Create project directory
mkdir docker-app
cd docker-app
Step 2: Create Python file
nano app.py
Step 3: Write program
from flask import Flask
app = Flask(__name__)

@app.route('/')
def home():
    return "Hello from Docker App!"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8080)
Step 4: Create Dockerfile
nano Dockerfile
Step 5: Write Dockerfile
FROM python:3.10-slim

WORKDIR /app

COPY app.py .

RUN pip install flask

EXPOSE 8080

CMD ["python3", "app.py"]
Step 6: Build Docker image
docker build -t flask-app .
Step 7: Run container
docker run -p 8080:8080 flask-app or 
docker run -d -p 8080:8080 flask-app
